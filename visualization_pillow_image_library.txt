# Pillow Image library

* <https://github.com/python-pillow/Pillow>

The library contains basic image processing functionality, including 
point operations, filtering with a set of built-in convolution 
kernels, and colour space conversions.

The library also supports image resizing, rotation and arbitrary 
affine transforms.

There’s a histogram method allowing you to pull some statistics out 
of an image. This can be used for automatic contrast enhancement, and 
for global statistical analysis.

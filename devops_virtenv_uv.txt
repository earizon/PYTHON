# uv Pkg. manager, Ruff linter and ty type-checker, Rust based By Astral

- x10-100 faster than python alternatives.

## Daily use:

```
$ V="3.14.2"
$ ARCH=linux-"x86_64"                       #
$ PYTHON_VERSION="cpython-${V}-${ARCH}-gnu" # Check with `uv python list` for alternatives (include freethreaded)
$ uv python install ${PYTHON_VERSION}       # install different versions of python in parallel
$ uv python dir                             # Show the uv Python installation directory
$ uv python pin ${PYTHON_VERSION}           # "pin" to this version of Python
$ uv python update-shell                    # Update .bashrc ... Ensure Python exec. is on the PATH.
$ mkdir project1 && cd project1
uv init . \
   --name project1 \
   --app
   --no-description \
   --build-backend uv \
   --author-from git \
   --no-pin-python \
   --no-workspace \
   --python 3.14 \
   --managed-python \
   --color never \
   --native-tls                           # init project (Check uv init --help for details)
(A layout similar to next one will be created)
  project1/
    }- pyproject.toml    #  wih sections project, project.scripts, build-system
    }- README.md
    }- .python-version
    }- src/uv_test/__init__.py
  

$ uvx ty check  # execute type check (== uv tool run ty, without previous install)

# Lint files (Alt 1, with no previous linter install)
# ruff (Rust based), 10-100x faster than other linters and formatters
# - 800 built-in rules.

uvx ruff check   # Lint all files in the current directory.
uvx ruff format  # Format all files in the current directory.
#
# uv tool install ruff@latest# Alt 1.1: Install globally with uv
# uv add --dev ruff          # Alt 1.2: Add Ruff to project.
#
# pip install ruff           # Alt 2.1: Install using pip.
# pipx install ruff          # Alt 3.1: Install using pipx.

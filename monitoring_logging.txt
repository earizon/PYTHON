## Logging (Advanced use)

Basic classes defined by the logging module:

*  LogRecord: Log event information is passed between loggers, handlers, filters and formatters in 
              a **LogRecord instance**.
*    Loggers: expose the interface (debug,info,...) used by final apps.
*   Handlers: send log records (created by loggers) to the appropriate destination.
              (HTTP GET/POST, queue, syslog, ...)
*    Filters: provide finer grained facility for determining which log records to output.
* Formatters: specify the layout of log records in the final output.


  Logged messages to the module-level logger get forwarded to handlers of loggers 
in higher-level modules, all the way up to the highest-level logger known as 
the root logger; this approach is known as hierarchical logging.


  ```
  | # Advanced use ─────────────────────────────────────────────────────────────
  | 
  | logger = logging.getLogger(__name__) # <·· Get logger instance.
  |                                      # ------
  |                                      # name   <·· conceptually arranged in a namespace `package.module`
  |                                      #            matching/tracking the package/module hierarchy
  |                                      #            scan       <·· root logger in hierarchy
  |                                      #            scan.text
  |                                      #            scan.html
  |                                      #            scan....
  ```

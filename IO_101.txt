## 'with' Context Manager:

* Python can automatically release used memory thanks to its 
  garbage collector.
* External resources (outside the control of the CPU) can not
  be automatically released when not used anymore. To avoid
  forgetting to close them, we can use the `with` syntax sugar.

  ```
  | with open(filename) as openFile:    # After block openFile.close()
  |     file_contents = openFile.read() # is automatically invoked.
  | ...                                    
  ```

# unittest (built-in)

* inspired by Java’s JUnit. 
* supports test discovery, test setup/teardown and test suites.



  ```
  |import unittest
  |
  |class TestStringMethods(unittest.TestCase):
  |    def test_upper(self):
  |        self.assertEqual('foo'.upper(), 'FOO')
  |
  |    def test_isupper(self):
  |        self.assertTrue('FOO'.isupper())
  |        self.assertFalse('Foo'.isupper())
  ```

## unittest.mock


* Allows to replace external components while unit-testing.
  as well as track function calls and return values.

  ```
  |from unittest.mock import Mock
  |
  |mock = Mock()
  |mock.return_value = 42
  |assert mock() == 42
  ```

## unittest.TestCase Assertions

  ```
  |assertEqual(a, b)
  |assertTrue(x)
  |assertRaises(Error, func, *args)
  ```

## unittest.TestLoader and TestSuite: 
* Manage groups of related tests.

  ```
  |suite = unittest.TestLoader().loadTestsFromTestCase(TestStringMethods)
  |unittest.TextTestRunner().run(suite)
  ```

# pytest  (pip install pytest)

* most popular testing framework.
* More concise and powerful than unittest.
* Features: Fixtures, parameterized testing, plugins.
* More pytest-idiomatic.
  ```
  | def funcA(x):
  |     return x + 1
  | 
  | def test_funcA():
  |     assert func(3) == 4
  ```

## Spies

* A spy is a type of mock that records how it was called (arguments, number of calls, etc.)
  but **doesn’t replace the actual implementation unless you want it to**.

  ```
  | Example: Spying on a Function
  | # my_module.py
  | def greet(name):                                   # <·· "low level" function to be spied.
  |     return f"Hello, {name}!"
  | 
  | def say_hello():                                   # <·· "High level" function directly invoked
  |     return greet("Alice")                          #     by users (or tests).
  | 
  | Test with Spy:
  | 
  | from unittest.mock import patch                    # <·· Using standard unittest.mock.patch
  | from mod01 import say_hello, greet                 #     to "wrap" the real function invoked.
  | 
  | def test_spy_on_greet():
  |   with patch("mod01.greet", wraps=greet) as SPY:   # <·· Wrap and spy "greet" without changing
  |     result = say_hello()                           #     origina behavior 
  |     assert result == "Hello, Alice!"
  |     SPY.assert_called_once_with("Alice")           # check calls to function being spied (tracked)
  ```

## . Mocking Properties


  ```
  | Example: Mocking a Property
  | 
  | # my_module.py
  | class User:
  |     @property
  |     def name(self):               # <·· Python property to be mocked
  |         return "Alice"
  | 
  | def get_user_name():
  |     user = User()
  |     return user.name
  | 
  | from my_module import get_user_name, User
  | 
  | def test_mock_or_spy_prop():      # Alt 1: Using standard unittest lib.
  |    from unittest.mock
  |      import  patch, PropertyMock
  |     with patch.object(            # <·· Mock (callable) property
  |        User, "name",
  |        new_callable=PropertyMock
  |        # wraps=User.name          # <·· use wrap to spy the property -vs mocking-
  |     ) as MOCK:
  |         MOCK.return_value = "Bob"
  |         result = get_user_name()
  |         assert result == "Bob"
  |         # assert MOCK.call_count == 1 # <·· (when spied/wrapped vs mocked)
  | 
  | def test_mock_or_spy_prop(mocker):# Alt 2: using pytest-mock (pip install pytest-mock)
  |     mocker.patch.object(          # <·· Mock (callable) property
  |        User, "name",
  |        new_callable=mocker.PropertyMock,
  |        return_value="Bob")
  |     user = User()
  |     assert user.name == "Bob"
  | 
  |     spy = mocker.spy(User, "name")# <·· Spy (callable) property
  |     user = User()
  |     assert user.name == "Alice"
  |     spy.assert_called_once()
  ```

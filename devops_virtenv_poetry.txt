# poetry (mvn/npm/... for Python)

- Packaging and packagin dependency tool.

  ```
  | ─ POETRY INSTALL ───────────────────────
  | $ pip3 install \
  |   --user \
  |   poetry                    # <· Install poetry for current user at:
  |                             #    ~/.local/lib/python3.XX/site-packages/poetry/...
  |                             #    - Use `--upgrade` flag to upgade 
  |                             #      existing install
  |
  | ── DAILY USE ───────────────────────────
  |                                         
  | $ poetry new projectA       # <·· Bootstrap new project
  |   
  |  Output layout similar to:
  |  projectA/
  |  ├─ pyproject.toml          # <·· ORCHESTRATE PROJECT DEPS.
  |  │                                Similar to `requirements.txt` in pip or
  |  │                                `*yaml` in Conda
  |  │  
  |  │  ┌─ ¹ pyproject.toml example ────┐
  |  │  │ [tool.poetry]                 │
  |  │  │ name = "projectA"             │
  |  │  │ version = "0.1.0"             │
  |  │  │ description = ""              │
  |  │  │ authors = ["name <mail>"]     │
  |  │  │                               │
  |  │  │ [tool.poetry.dependencies]    │
  |  │  │ python = "*"                  │
  |  │  │ pendulum = "^1.4"             <·· Edit manually or use:
  |  │  │                               │   `$ poetry add    pendulum` 
  |  │  │ [tool.poetry.dev-dependencies]│   `$ poetry remove pendulum`
  |  │  │ pytest = "^3.4"               │
  |  │  └───────────────────────────────┘
  |  │
  |  ├─ README.rst 
  |  ├─ poetry_demo
  |  │  └─ __init__.py
  |  └─ tests
  |     ├─ __init__.py
  |     └─ test_poetry_demo.py
  |
  | $ poetry  install             # <·· Install declared dependencies
  ```

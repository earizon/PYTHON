* Guido Van Rosum: Python creator.

* Tim Peters: <https://en.wikipedia.org/wiki/Tim_Peters_(software_engineer)>
  Well known for creating the Timsort hybrid sorting algorithm and major
  contributions to the Python programming language and CPython implementation.
  A pre-1.0 CPython user, he was among the group of early adopters who 
  contributed to the detailed design of the language in its early stages.
  - Timsort algorithm is/was used in Python since version 2.3 (now replaced by
    a variant alternative), as well as the V8 JavaScript engine.

* Companies/Projects
  <http://www.pocoo.org/>
    Pocoo was a loosely assembled team of Open Source developers working on some
    very popular Python projects. Out of this came the Pygments syntax highlighter
    , the Sphinx documentation system, the Flask web framework, the Jinja
    templating engine, the Werkzeug WSGI library, the Click command line toolkit
    and much more. It was led by Armin Ronacher and Georg Brandl.

* Jens Vagelpohl: Zope and CMF core developer
